# CPIP Frontend

Career & Placement Intelligence Platform — Frontend Application

## Setup

### 1. Install Node.js
Download from https://nodejs.org/ (LTS version)

### 2. Install Dependencies
```bash
npm install
```

### 3. Run Frontend
```bash
npm run dev
```

Frontend runs at: `http://localhost:5173`

### 4. Build for Production
```bash
npm run build
```

## Notes
- Frontend connects to backend at http://localhost:8000
- Health check shows backend status
- Uses React 18 and Vite
