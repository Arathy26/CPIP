Stage 1 — Phase 1.4
Skill Gap Agent

What I Built

In Phase 1.4, I built the second CPIP agent — the Skill Gap Agent. This agent reads a candidate's skills and compares them with target role requirements, then calculates a gap score and identifies missing skills.

The Complete Agent

  • ✅ Skill Gap Agent Code — Python function that compares skills and calculates gap score
  • ✅ API Endpoints — FastAPI routes to evaluate skill gaps for students
  • ✅ Gap Scoring Logic — Produces 0-100 score based on skill match percentage
  • ✅ Readiness Levels — Classifies students into readiness categories

Career & Placement Domain Learning

I learned that skill gaps are the foundation of career readiness planning.

Key Insight:

In real placement, students don't just need jobs — they need direction. By understanding exactly which skills they lack compared to their target role, students can focus their training effort on what matters most. A skill gap of 25 is very different from a skill gap of 75, and the training recommendations should reflect that difference.

Why Skill Gaps Matter in Placement

Without knowing gaps:

  • ❌ Students apply to unsuitable roles
  • ❌ Students fail interviews without knowing why
  • ❌ Training is unfocused and inefficient

With skill gap analysis:

  • ✅ Students know exactly what to learn
  • ✅ Mentors can create targeted training plans
  • ✅ Students have realistic preparation timelines

Agentic AI Learning

I learned that agentic systems produce measurable outputs (scores) so downstream agents can make decisions.

The Scoring Principle:

In Phase 1.3, agents transformed data. In Phase 1.4, agents score data. The Skill Gap Agent produces a score (0-100) that other agents can use to decide next actions. This is how agentic systems coordinate: each agent produces a measurable output that feeds into the next agent's decision logic.

Agent Coordination Flow

Candidate Profile (Phase 1.3) ↓ Skill Gap Agent (Phase 1.4) ├─ Compares skills ├─ Calculates gap score └─ Identifies missing skills ↓ Gap Score + Missing Skills ↓ (Phase 1.5+: Other agents use this) ├─ Training Recommendation Agent │ → "Student needs Python + ML training" ├─ Role Matching Agent │ → "Student is not ready for AI Engineer yet" └─ Interview Readiness Agent → "Focus prep on technical fundamentals"

Why This Matters: The skill gap score is a measurable signal that other agents can understand and act on, without needing to re-analyze the same data.

Known Limitations

⚠️ Sample Role Requirements (Not Real Database):

For Phase 1.4 MVP, role requirements are hardcoded in the API route. This was intentional for testing. In Phase 1.14+, we'll query real JOB_REQUIREMENT table from the database. For now, we've proven the gap analysis logic works correctly.

⚠️ Sample Student Skills (Not Real Database):

Student skills are also hardcoded in the API route from seed data. Same principle — we're testing the agent logic, not the database integration. The agent code is independent of data source.

✅ This Is Acceptable Because:

We're validating the gap calculation algorithm and API communication work correctly. The agent will work exactly the same way when connected to real STUDENT_SKILL and JOB_REQUIREMENT tables.

Key Takeaway

Agentic systems coordinate through measurable outputs.

Phase 1.3 transformed data into a structured format. Phase 1.4 evaluated that data and produced a score. The next agent (Training Recommendation) will use this score to make decisions about what the student should learn next. This is how agentic AI scales: each agent has a clear input, clear logic, and measurable output that the next agent can understand and use.
